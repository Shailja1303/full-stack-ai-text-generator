# Full Stack AI Text Generator

A full-stack AI text generation web application built using Flask, JavaScript, HTML, CSS, and Hugging Face Transformers.

## Features

- Generate AI text from user prompts
- Flask backend API
- JavaScript frontend
- Hugging Face Transformer integration
- Responsive UI

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Hugging Face Transformers
